            Settings

            Theme

            OpenFreeMap has a real dark style. OpenStreetMap and the topographic map are shown with inverted colours in dark mode. Satellite and Google maps keep their own colours. The map's layer button switches maps too.

            Single-key shortcuts work whenever you are not typing in a box. Click a key to change it, then press the new letter or number. W A S D also move the joystick while the Joystick tab is open.

            Lets routes come from Google Maps. Create a key in Google Cloud and enable Routes API and Map Tiles API. Google bills per request after its free tier. Google routes are shown on Google's own map (Google's terms require it) and cannot be exported as GPX. The key is stored only on this computer.

            The app checks GitHub when it starts and every few hours, downloads updates in the background and verifies their SHA-256 checksum.
